# AKS Hands-On: End-to-End DevOps Practice

This repository demonstrates an end-to-end DevOps workflow using **Docker, Kubernetes (AKS), Terraform, and GitHub Actions**.

The project covers:
- Infrastructure creation using Terraform
- Containerizing a sample application using Docker
- Deploying the application to AKS
- CI/CD pipelines using GitHub Actions
- Environment separation using Kubernetes namespaces (`dev` and `prd`)

---

## 🛠 Tech Stack

- **Cloud**: Microsoft Azure
- **Kubernetes**: Azure Kubernetes Service (AKS)
- **IaC**: Terraform
- **Containerization**: Docker
- **CI/CD**: GitHub Actions
- **Application**: Node.js (Express)
